# Phase 0 — foundation: plan (web app)

## Structure

`src/api/` (generated client + wrapper), `src/design/` (tokens, `parties.ts` placeholder
with no party yet), `src/i18n/es.ts`, `src/routes/` (root layout and index route),
`src/features/health/` (hook + small status component, removed or kept as a footer
status later).

## Dependencies (to approve)

Runtime: `react`, `react-dom`, `react-router` (v7), `zod`, `@tanstack/react-query` (data
hooks with cache, loading and error states), `openapi-fetch`.
Dev: `vite`, `typescript`, `@vitejs/plugin-react`, `openapi-typescript`, `eslint`,
`typescript-eslint`, `eslint-plugin-react-hooks`, `eslint-plugin-jsx-a11y`, `prettier`,
`vitest`, `jsdom`, `@testing-library/react`, `@testing-library/user-event`, `msw`,
`vitest-axe`.

Exact versions are pinned when installing, after checking the current releases.

Approved by the author on 2026-10-13, after checking versions and peer dependencies:

- `react-router` **v8** (8.4): the current major since 2026-06-17. Every v8 change was
  already available in v7 behind future flags, so ADR-0004 (React Router, server
  rendering later) is unchanged; only the major version moved.
- `typescript` **5.9**, not 7: `typescript-eslint` needs < 6.1 and `openapi-typescript`
  needs 5.x.
- `eslint` **9**, not 10: `eslint-plugin-jsx-a11y` supports up to 9.
- `axe-core` directly with a small test helper, instead of `vitest-axe` (unmaintained
  since 2022).
- Plus `d3-geo` for the map (approved in `map-governments`), `@testing-library/jest-dom`,
  `@eslint/js`, `globals` and the type packages.

## Decisions

| Decision | Choice | Record |
|---|---|---|
| Package manager | pnpm | plan only |
| Data fetching | TanStack Query in hooks | plan only; front ADR if the author wants it argued |
| API client | `openapi-typescript` types + `openapi-fetch`, regenerated by script | plan only |
| Styling | CSS with custom properties (tokens) and CSS modules; no UI kit yet | plan only |

## Risks

- React Router v7 framework vs. library mode: start in library (SPA) mode; the switch to
  framework mode for server rendering is planned in `story-contrast`. To verify that the
  migration is incremental before that phase.
