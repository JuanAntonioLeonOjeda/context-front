# Proposals

Drafts that frame a decision before it is taken: the problem, the options with trade-offs,
a recommendation and the open questions for the author. A proposal is not a decision. Once
the author decides, it becomes an ADR (`../adr/` for front-only, `../../back/docs/adr/` for
project-wide) and, if it is a feature, a `specs/<phase>/` spec.
